# Glossary

| Term | Definition |
| --- | --- |
| **Playbook** | Configuration container defining a quoting operating motion—questions, rules, approvals, and view sections |
| **Playbook Question** | User input prompt that drives Quote configuration |
| **Playbook Scenario** | Boolean condition built from criteria; gates rules, approvals, and view sections |
| **Playbook Rule** | Automation container that executes actions when its scenario and timing conditions are met |
| **Rule Action** | Individual automation step (add product, stamp answer, adjust visibility, etc.) |
| **Calculation Item** | Value source used in rule action formulas |
| **Playbook Approval** | Configuration record defining when approval is required |
| **View Section** | Blueprint for a section in a proposal PDF or approval email |
| **Pricing Set** | Tiered pricing configuration linked to products via identifier |
| **Pricing Threshold** | Numeric tier range within a pricing set |
| **Shell Quote** | Temporary quote created for proposal preview during edit; receives draft watermark |
| **Sync** | Push Quote and line item field values to Opportunity and Opportunity Products |
| **Contract Entitlement** | Product entitlement record on a Contract |
| **Adjustment Type** | Amendment, Replacement, or Renewal—defines how a contract-sourced Quote modifies the deal |
| **Entitlement Combination** | Merging multiple entitlements during contract amendment |
| **Power User** | User-level flag granting elevated CPQ, Approvals, Contracts, or Proposals capabilities |
| **Redline** | Quote-specific View Section override for custom proposals |
| **Piped text** | Token syntax (`{%VariableName%}`) inserting dynamic values into text and queries |
| **Date split** | Splitting a line item into multiple records across date ranges |
| **System Settings** | Org-wide CPQ configuration record controlling UI tables and defaults |
