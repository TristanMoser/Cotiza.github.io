# Version 0.2.0

Release Date: July 2026

## Features

- **Sum Product** operation on Entitlement Combination Mapping — evaluate a custom formula per adjustment entitlement and sum the results when combining entitlements during contract amendments
- **Renewal pricing defaults** — renewal entitlement lines derive full-term base list price, base unit price, and discount from underlying contract entitlements rather than prorated values
- **Extended formula syntax** — custom formulas on Pricing Sets, Pricing Thresholds, Rule Calculation Items, and Entitlement Combination Mappings now support comparison operators and ternary expressions

## Improvements

- Default discount combination formula now uses SubTotal and Total price fields for accurate weighted discount calculation
- **Field Type** and **Operation** are required on Entitlement Combination Mapping records
- Shell quotes no longer reuse existing Playbook Answer record IDs during proposal preview
- Month-based proration correctly includes the final day when the end date falls on a period boundary

## Fixes

- Corrected month proration calculation when line item end date equals the proration period boundary (`end <= topBound`)
