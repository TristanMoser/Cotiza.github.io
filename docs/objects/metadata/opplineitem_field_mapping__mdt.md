# OppLineItem Field Mapping

Facilitates field mappings from QuoteLineItem to OpportunityLineItem records.

| API Name | Label | Description |
| --- | --- | --- |
| `OpportunityLineItem_Field__c` | OpportunityLineItem Field | OpportunityLineItem Field API name that should be pull from source QuoteLineItem |
| `QuoteLineItem_Field__c` | QuoteLineItem Field | QuoteLineItem Field API name that value should be mapped to synced OpportunityLineItem |
