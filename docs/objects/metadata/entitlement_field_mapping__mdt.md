# Entitlement Field Mapping

Facilitates field mappings from OpportunityLineItem to Contract Entitlement records.

| API Name | Label | Description |
| --- | --- | --- |
| `Entitlement_Field__c` | Entitlement Field | Cotiza__Contract_Entitlement__c Field API name that value should be mapped to new Entitlement |
| `OpportunityLineItem_Field__c` | OpportunityLineItem Field | OpportunityLineItem Field API name that should be pull from source OLI |
