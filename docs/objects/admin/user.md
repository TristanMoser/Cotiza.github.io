# User

Standard SFDC User object.

| API Name | Label | Description |
| --- | --- | --- |
| `Power_User__c` | Power User | Scenarios in which the User has elevated functionality. 'CPQ' allows the User full access to all all quote configuration. 'Approvals' allows the User to view and act on any Approvals. 'Contracts' allows the User to void Contracts. 'Proposals' allows the User to override View Sections with redlines and generate Word Doc proposals. |
