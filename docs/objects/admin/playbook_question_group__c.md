# Playbook Question Group

Container for Playbook Questions to be grouped visually within a Playbook.

| API Name | Label | Description |
| --- | --- | --- |
| `Default_Collapsed__c` | Default Collapsed | Determines if the question group is collapsed or not when initially loaded in CPQ |
| `Display_Order__c` | Display Order | Order in which group should be displayed in its playbook. Lower numbers appear first |
| `IsActive__c` | Is Active | Determines if group is active and should be evaluated in its CPQ Playbook |
| `IsHidden__c` | Is Hidden | Determines if Users can see this group in CPQ. If not, the group is still evaluated, but not shown |
| `Label_Icon__c` | Label Icon | Icon displayed before label in CPQ. Example: utility:question_mark |
| `Label__c` | Label | Displayed label Users see in CPQ |
| `Max_Height__c` | Max Height | CSS Size to apply as the maximum height for the Question Group |
| `Playbook__c` | Playbook | Playbook to which this question group belongs |
