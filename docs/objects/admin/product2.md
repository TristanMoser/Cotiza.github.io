# Product

Standard SFDC Product2 object referenced by line items.

| API Name | Label | Description |
| --- | --- | --- |
| `Do_Not_Create_Entitlement__c` | Do Not Create Entitlement | Determines if an Opportunity Line Item with this Product should NOT create a Contract Entitlement record |
| `Do_Not_Upgrade_Entitlement__c` | Do Not Upgrade Entitlement | Contract upgrade scenario(s) where product should not be pulled in for a Contract adjustment quote from an entitlement |
