# Price Book

Standard SFDC Pricebook2 object referenced by a Playbook.

| API Name | Label | Description |
| --- | --- | --- |
| `Currency__c` | Currency | Currency ISO Code child price book represents |
| `Parent_Price_Book__c` | Parent Price Book | Parent price book this price book is based off of. Parent Price Book is used in CPQ for playbooks and child price books are copies in different currencies. |
