# Quote Approval

Output for Playbook Approval from a Quote Playbook configuration.

| API Name | Label | Description |
| --- | --- | --- |
| `Notes_for_Approvers__c` | Notes for Approver(s) | Notes/Justification submitted to approver(s) |
| `Playbook_Approval__c` | Playbook Approval | Playbook Approval to which the Approval tracks for the Quote |
| `Quote__c` | Quote | Quote to which the Approval belongs |
| `Status__c` | Status | Current status of Approval on Quote |
