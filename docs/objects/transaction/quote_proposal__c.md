# Quote Proposal

Generated document based on View Sections from a Quote Playbook configuration.

| API Name | Label | Description |
| --- | --- | --- |
| `Download_Link__c` | Download Link | Click to download generated document |
| `IsDraft__c` | Is Draft | Tracks whether or not proposal was generated while the quote was still unapproved |
| `Quote__c` | Quote | Quote to which the Proposal was generated from |
| `View_Link__c` | View Link | Click to view generated document |
